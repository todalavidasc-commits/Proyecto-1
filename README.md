# Demostración de Auditoría: Parrot OS & vsftpd Exploit (CVE-2011-2523)

Este repositorio contiene la documentación y demostración práctica de una auditoría de seguridad realizada en un entorno de laboratorio controlado.

##  Video de la Demostración

Haz clic en la imagen de abajo para ver el video completo de la auditoría en YouTube:

[![Auditoría Parrot OS](https://youtube.com)](https://www.youtube.com/watch?v=VcUWSjQ0u5c&t=135s)

##  Ejercicios Realizados

1. **AnonSurf**: Enrutamiento de todo el tráfico del sistema a través de la red Tor para cambiar la IP pública, priorizando el anonimato y la privacidad durante la fase de reconocimiento.
2. **Explotación de vsftpd 2.3.4 (CVE-2011-2523)**: Aprovechamiento de una vulnerabilidad de backdoor conocida en el servicio vsftpd utilizando el Metasploit Framework, teniendo como objetivo una máquina de prueba Metasploitable.
